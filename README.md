# JRPG Environment Project

A Godot fantasy-world and environment prototype, including Starter Valley and Green River Overworld source resources.

## Contents and current limits

The Godot project is at hero-jrpg/project.godot. Scene/material definitions, GDScript and selected design documentation are included. Downloaded textures and binary Blender/model files are omitted, including models that embed third-party textures. This source selection is incomplete for play without its local media.

This is a curated public copy of the local project. Publication documentation
exists only in this separate copy. The original project is not modified.
Imported source files retain their original relative paths and contents.
No prior Git history, credentials, local caches, backups, or bundled tools
are included.
